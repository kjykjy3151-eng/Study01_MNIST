# 손글씨 숫자 인식기 (MNIST + PyTorch)

마우스로 그린 숫자를 CNN이 0~9 중 하나로 알아맞힙니다. 두 가지로 쓸 수 있습니다.

| | 웹 버전 | 데스크톱 버전 |
| --- | --- | --- |
| 위치 | `web_version/` | `desktop_version/` |
| 설치 | 필요 없음. 주소만 열면 됩니다 | Python 과 PyTorch 설치 |
| 쓰는 것 | 순수 자바스크립트 (외부 라이브러리 없음) | Python, PyTorch, Tkinter |
| 학습 | 할 수 없음 (학습된 가중치를 그대로 씁니다) | `train.py` 로 직접 학습 |

두 버전은 **같은 가중치와 같은 전처리 규칙**을 씁니다. 같은 그림을 넣으면
같은 숫자를 예측합니다. 이 동등성은 자동 시험으로 확인합니다
(아래 [웹 버전](#웹-버전) 참고).

## 브라우저에서 바로 써 보기

GitHub Pages 로 게시하면 설치 없이 바로 쓸 수 있습니다.

1. 저장소 설정의 **Settings → Pages** 에서 Source 를 `main` 브랜치 루트로 지정합니다.
2. 잠시 뒤 `https://<계정>.github.io/study01_MNIST/` 로 들어가면 웹 버전이 열립니다.

로컬에서 확인하려면 `web_version` 폴더에서 아래를 실행하고
`http://localhost:8000/` 을 엽니다. ES 모듈과 `fetch` 는 `file://` 에서
동작하지 않아 간단한 서버가 필요합니다.

```bash
../desktop_version/.venv/Scripts/python.exe -m http.server 8000
```

## 설치

여기부터는 **데스크톱 버전** 이야기입니다. 웹 버전만 쓸 거라면 설치할 것이 없습니다.

**필요한 것**: Python 3.10 ~ 3.15 (3.9 이하는 PyTorch 휠이 없습니다)

**`desktop_version` 폴더 안에서** 아래 두 줄을 실행하면 끝납니다. 내려받는 용량은
약 130MB, 설치는 보통 1~2분 걸립니다. 가상환경 `.venv` 는 반드시 이 폴더 안에
만들어야 합니다. 실행 스크립트들이 자기 옆의 `.venv` 를 찾기 때문입니다.

**Windows**

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**macOS / 리눅스**

```bash
python3 -m venv .venv
```

```bash
.venv/bin/python -m pip install -r requirements.txt
```

`requirements.txt` 는 PyTorch를 **CPU 전용 인덱스**에서 받도록 지정해 두었습니다.
이 앱은 GPU를 쓰지 않는데, 기본 PyPI를 쓰면 Windows에서 CUDA가 포함된
2.5GB짜리 꾸러미를 받게 되고 내부 경로가 길어 설치가 실패하는 경우도 있기 때문입니다.

학습된 가중치 `mnist_cnn.pt` 가 저장소에 함께 들어 있으므로,
**재학습 없이 바로 앱을 실행할 수 있습니다.**

**Windows**

```bash
.venv\Scripts\python.exe app.py
```

**macOS / 리눅스**

```bash
.venv/bin/python app.py
```

맥에서 처음 받았다면 실행 파일에 권한을 한 번 줘야 파인더에서 더블클릭할 수 있습니다.

```bash
chmod +x "손글씨 인식 앱 실행.command"
```

그다음부터는 파인더에서 **`손글씨 인식 앱 실행.command`** 를 더블클릭하면 됩니다.
처음 한 번은 "확인되지 않은 개발자" 경고가 뜰 수 있는데,
`제어 키를 누른 채 클릭 → 열기` 로 실행하거나
`시스템 설정 → 개인정보 보호 및 보안` 에서 `확인 없이 열기` 를 누르면 됩니다.

## 실행

아래 명령은 모두 `desktop_version` 폴더 안에서 실행합니다.

1. 모델 학습 (처음 한 번만, CPU 기준 약 10~20분)

   ```bash
   python train.py
   ```

   에포크 수를 바꾸려면 `python train.py --에포크 10` 처럼 지정합니다.
   학습이 끝나면 같은 폴더에 `mnist_cnn.pt` 가 생깁니다.

2. 손글씨 인식 앱 실행

   ```bash
   python app.py
   ```

   검은 화면에 숫자를 **크게 하나** 그리고 마우스에서 손을 떼면 결과가 나타납니다.
   `지우기` 버튼이나 `Esc` 키로 캔버스를 비울 수 있습니다.

## 바탕 화면에서 실행하기

바로 가기를 먼저 만듭니다. 바탕 화면과 프로젝트 폴더에 하나씩 생깁니다.

```bash
powershell -ExecutionPolicy Bypass -File 바로가기_만들기.ps1
```

바로 가기 파일(`.lnk`)에는 만든 PC의 절대 경로와 컴퓨터 이름이 기록되기 때문에
저장소에는 포함하지 않았습니다. 그래서 내려받은 뒤 한 번 실행해 주어야 합니다.

이제 바탕 화면의 **`손글씨 숫자 인식기`** 를 더블클릭하면 검은 콘솔 창 없이 앱만 뜹니다.

### 작업 표시줄에 고정하기

두 가지 방법 중 편한 쪽을 쓰면 됩니다.

1. 바탕 화면 아이콘에서 **마우스 오른쪽 버튼 → 작업 표시줄에 고정**
   (Windows 11에서는 `추가 옵션 표시`를 먼저 눌러야 나올 수 있습니다)
2. 앱을 실행한 뒤, 작업 표시줄에 생긴 아이콘에서 **오른쪽 버튼 → 작업 표시줄에 고정**

고정한 아이콘과 실제 실행 중인 창이 따로 놀지 않고 하나로 묶이는 이유는,
바로 가기와 앱이 같은 식별자(`AppUserModelID`)를 쓰도록 맞춰 두었기 때문입니다.
바로 가기에는 `PKEY_AppUserModel_ID` 속성으로, 앱에서는 `작업표시줄_아이디_설정()`
함수가 `SetCurrentProcessExplicitAppUserModelID` 를 호출해 등록합니다.
이 설정이 없으면 윈도우가 앱을 그냥 '파이썬'으로 인식해서 단추가 두 개로 갈라집니다.

## 파일 탐색기에서 더블클릭으로 실행하기

`desktop_version` 폴더 안에서도 아래 셋 중 아무거나 더블클릭하면 실행됩니다.

| 더블클릭할 파일 | 설명 |
| --- | --- |
| `손글씨 숫자 인식기.lnk` | 가장 깔끔합니다. 콘솔 창이 전혀 뜨지 않습니다. (위 스크립트로 생성) |
| `손글씨 인식 앱 실행.bat` | 가상환경과 가중치가 없으면 이유를 알려 줍니다. |
| `app.py` | `.py` 확장자가 파이썬 런처에 연결되어 있어야 합니다. |

`app.py`를 직접 더블클릭해도 동작하는 이유는, `app.py` 안의 `가상환경으로_재실행()`
함수가 현재 파이썬에 PyTorch가 없으면 `desktop_version/.venv` 의 실행기로
자기 자신을 다시 실행하기 때문입니다. 덕분에 시스템에 연결된 파이썬이
어떤 것이든 앱이 정상적으로 뜹니다.

`.py` 확장자 연결을 바꾸거나 되돌리려면 (관리자 권한 없이, 사용자 계정 범위):

```bash
reg add "HKCU\Software\Classes\.py" /ve /d "Python.NoConFile" /f
```

```bash
reg delete "HKCU\Software\Classes\.py" /f
```

> 더블클릭 실행은 콘솔이 없어서 오류 메시지가 보이지 않습니다.
> 그래서 `app.py`는 예상 못 한 오류를 대화상자로 띄워 줍니다.

## 웹 버전

웹 버전은 **외부 자바스크립트 라이브러리를 하나도 쓰지 않습니다.** 빌드 단계도,
번들러도 없습니다. 합성곱, 최대풀링, 완전연결, 소프트맥스를 `Float32Array` 반복문으로
직접 계산하며, 추론 1회에 약 1,200만 번의 곱셈누산을 수행하고도 보통 노트북에서
수십 밀리초면 끝납니다.

데스크톱과 같은 답을 내는지는 자동 시험으로 확인합니다. MNIST 평가셋 앞 200장을
10배로 확대해 '그림판에 그린 그림'으로 삼고, 파이썬 쪽 결과와 대조합니다.
외부 패키지 없이 Node 만 있으면 됩니다.

```bash
node web_version/테스트/검증.mjs
```

확인하는 것은 다음 일곱 가지입니다.

1. 같은 28×28 입력에서 PyTorch 와 같은 확률 (오차 1e-4 이내, 예측 200개 일치)
2. 같은 그림에서 파이썬 전처리와 같은 28×28 (픽셀 오차 2/255 이내)
3. 전처리부터 추론까지 이어 붙인 최종 예측 200개 일치
4~7. 빈 캔버스, 점 하나, 극단적 종횡비, 꽉 채운 캔버스에서의 동작

실제로 측정하면 전처리 차이는 156,800 픽셀 중 4개가 1/255 만큼일 뿐이고,
최종 예측은 200개가 모두 같습니다.

가중치는 학습된 `mnist_cnn.pt` 를 float32 로 펼친 4.6MB 바이너리입니다.
데스크톱에서 재학습했다면 아래로 다시 만들어야 웹 버전에 반영됩니다.

```bash
cd web_version/도구 && ../../desktop_version/.venv/Scripts/python.exe 가중치_내보내기.py
```

### 알려진 차이

브라우저 캔버스는 선을 안티에일리어싱해 그리고, 데스크톱의 PIL 은 경계가 딱
떨어지게 그립니다. 그래서 같은 마우스 궤적이라도 두 앱의 입력 그림은 픽셀 단위로
조금 다릅니다. 뒤이은 20픽셀 축소가 어차피 부드럽게 만들기 때문에 인식 결과에는
영향이 없습니다.

## 모델 구조

```
입력 (1, 28, 28)
  → 합성곱 32채널 3x3 + ReLU      → (32, 26, 26)
  → 합성곱 64채널 3x3 + ReLU      → (64, 24, 24)
  → 최대풀링 2x2                   → (64, 12, 12)
  → 드롭아웃 0.25 → 평탄화         → (9216,)
  → 완전연결 128 + ReLU + 드롭아웃 0.5
  → 완전연결 10 → 로그 소프트맥스
```

기본 설정(5 에포크)으로 학습하면 MNIST 평가셋에서 대략 99% 정확도가 나옵니다.

## 인식이 잘 되게 하는 두 가지 장치

- **학습 데이터 증강** — 마우스 글씨는 MNIST 원본보다 위치와 기울기가 제각각이라,
  학습할 때 무작위 회전(±10°)·이동(±10%)·확대축소(90~110%)를 적용했습니다.
- **MNIST와 같은 전처리** — MNIST는 숫자를 20x20 상자에 맞춰 넣고 픽셀 무게중심을
  28x28의 한가운데로 옮긴 데이터입니다. `app.py` 의 `전처리()` 함수가 그린 그림에도
  똑같은 규칙을 적용합니다. 오른쪽 아래 미리보기 칸에서 실제로 모델에 들어가는
  28x28 이미지를 확인할 수 있습니다.

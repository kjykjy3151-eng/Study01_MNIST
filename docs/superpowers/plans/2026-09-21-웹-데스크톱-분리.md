# 손글씨 인식 앱 웹/데스크톱 분리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 파이썬 앱을 코드 수정 없이 `desktop_version/` 으로 옮기고, 같은 가중치와 같은 전처리 규칙을 쓰는 순수 자바스크립트 웹 버전을 `web_version/` 에 만들어 GitHub Pages로 배포한다.

**Architecture:** 데스크톱 쪽은 모든 파일이 자기 위치를 기준으로 경로를 만들므로 `.venv` 까지 한 덩어리로 옮기기만 한다. 웹 쪽은 `mnist_cnn.pt` 를 float32 원시 바이너리로 내보내고, 합성곱과 완전연결을 `Float32Array` 반복문으로 직접 계산한다. 전처리는 PIL의 Lanczos 축소 규칙을 자바스크립트로 옮기고, 파이썬이 만든 골든 데이터와 대조해 동등성을 증명한다.

**Tech Stack:** 순수 자바스크립트 ES 모듈(외부 라이브러리 0개, 빌드 없음), Node 24의 `node:test`, 파이썬 3.12 + PyTorch 2.14(가중치 내보내기와 골든 데이터 생성 전용)

**Spec:** [docs/superpowers/specs/2026-09-21-웹-데스크톱-분리-설계.md](../specs/2026-09-21-웹-데스크톱-분리-설계.md)

## Global Constraints

- 웹 버전은 외부 자바스크립트 라이브러리를 하나도 쓰지 않는다. 빌드 단계도 없다.
- 코드, 주석, 독스트링, 사용자에게 보이는 문자열, 직접 정의하는 식별자는 모두 한글로 쓴다. 프레임워크가 이름을 고정하는 부분(`forward`, `__init__`, DOM API 이름)만 영어를 유지한다.
- 새로 만드는 파일은 첫머리에 `2026-09-21 18:08 KST` 형식의 생성 일시 주석을 넣는다. 시각은 추측하지 말고 `date -u -d "+9 hours" "+%Y-%m-%d %H:%M"` 으로 구한다. 기존 파일을 고칠 때는 넣지 않는다.
- 정규화 상수는 `평균 = 0.1307`, `표준편차 = 0.3081` 이다. 학습, 데스크톱 추론, 웹 추론 세 곳이 반드시 같아야 한다.
- 가중치 바이너리 `mnist_cnn.bin` 의 크기는 정확히 4,799,528 바이트다.
- `web_version/` 안의 모든 경로는 상대 경로로 쓴다. `/js/...` 같은 절대 경로는 저장소 이름이 붙는 Pages 주소에서 깨진다.
- `desktop_version/` 의 파이썬 네 개와 실행 스크립트 세 개는 **내용을 한 글자도 바꾸지 않는다.**
- 한국어 표기: 단순 열거에는 가운뎃점(·) 대신 쉼표를 쓴다. 완결된 문장인 UI 문구와 오류 메시지는 마침표로 끝낸다. 보조용언은 띄어 쓴다("불러와 주세요").
- 파이썬 실행은 `desktop_version\.venv\Scripts\python.exe` 로 한다. `pip` 는 `python -m pip` 형태로 쓴다.

- [ ] **Step 2: 내보내기 스크립트를 쓴다**

`web_version/도구/가중치_내보내기.py` 를 만든다. 첫 줄의 시각은 `date -u -d "+9 hours" "+%Y-%m-%d %H:%M"` 으로 구한 값을 쓴다.

```python
"""학습된 mnist_cnn.pt 를 웹 버전이 읽을 수 있는 원시 바이너리로 내보냅니다.

실행:
    ..\\desktop_version\\.venv\\Scripts\\python.exe 가중치_내보내기.py

만들어지는 파일
    ../가중치/mnist_cnn.bin  리틀엔디언 float32를 정해진 순서로 이어 붙인 것
    ../가중치/구조.json      각 텐서의 이름, 모양, 오프셋과 정규화 상수
"""
# 2026-09-21 18:08 KST

import json
import sys
from datetime import datetime, timedelta, timezone
from pathlib import Path

import torch

기준_폴더 = Path(__file__).resolve().parent
웹_폴더 = 기준_폴더.parent
원본_경로 = 웹_폴더.parent / "desktop_version" / "mnist_cnn.pt"
가중치_폴더 = 웹_폴더 / "가중치"

# 정규화 상수. desktop_version/train.py, app.py 와 반드시 같아야 합니다.
평균 = 0.1307
표준편차 = 0.3081

# 내보내는 순서입니다. 자바스크립트가 이 순서대로 잘라 읽으므로 바꾸면 안 됩니다.
내보낼_순서 = [
    ("합성곱1.weight", (32, 1, 3, 3)),
    ("합성곱1.bias", (32,)),
    ("합성곱2.weight", (64, 32, 3, 3)),
    ("합성곱2.bias", (64,)),
    ("완전연결1.weight", (128, 9216)),
    ("완전연결1.bias", (128,)),
    ("완전연결2.weight", (10, 128)),
    ("완전연결2.bias", (10,)),
]
기대_바이트 = 4_799_528


def 한국_시각():
    """생성 시각을 한국 표준시 문자열로 돌려줍니다."""
    return datetime.now(timezone(timedelta(hours=9))).strftime("%Y-%m-%d %H:%M KST")


def 메인():
    if not 원본_경로.exists():
        print(f"[오류] 가중치 파일을 찾을 수 없습니다: {원본_경로}")
        print("먼저 desktop_version 에서 train.py 로 학습해 주세요.")
        sys.exit(1)

    가중치_묶음 = torch.load(원본_경로, map_location="cpu")

    조각들 = []
    텐서_정보 = []
    시작 = 0
    for 이름, 기대_모양 in 내보낼_순서:
        if 이름 not in 가중치_묶음:
            print(f"[오류] 가중치에 {이름} 이(가) 없습니다. 모델 구조가 바뀌었는지 확인해 주세요.")
            sys.exit(1)
        텐서 = 가중치_묶음[이름]
        if tuple(텐서.shape) != 기대_모양:
            print(f"[오류] {이름} 의 모양이 {tuple(텐서.shape)} 입니다. {기대_모양} 이어야 합니다.")
            sys.exit(1)

        평탄한_값 = 텐서.detach().cpu().numpy().astype("<f4").ravel()
        조각들.append(평탄한_값.tobytes())
        텐서_정보.append({
            "이름": 이름,
            "모양": list(기대_모양),
            "시작": 시작,
            "개수": int(평탄한_값.size),
        })
        시작 += int(평탄한_값.size)

    가중치_폴더.mkdir(parents=True, exist_ok=True)
    이진_경로 = 가중치_폴더 / "mnist_cnn.bin"
    이진_경로.write_bytes(b"".join(조각들))

    실제_바이트 = 이진_경로.stat().st_size
    if 실제_바이트 != 기대_바이트:
        print(f"[오류] 만들어진 파일이 {실제_바이트} 바이트입니다. {기대_바이트} 바이트여야 합니다.")
```

최대풀링 결과의 메모리 배치가 (채널, 행, 열) 순서라, PyTorch의 `torch.flatten(x, 1)` 과 같은 순서가 이미 되어 있다. 그래서 평탄화는 따로 하지 않고 배열을 그대로 완전연결층에 넘긴다. 이 순서가 어긋나면 완전연결1의 가중치가 엉뚱한 픽셀에 곱해져 결과가 조용히 망가진다.

```javascript
// 2026-09-21 18:08 KST
//
// 외부 라이브러리 없이 숫자인식CNN 의 순전파를 계산합니다.
// desktop_version/model.py 의 숫자인식CNN 과 같은 연산을 같은 순서로 합니다.
//
// 이 파일은 DOM 에 의존하지 않습니다. 그래야 브라우저 없이 Node 에서
// 그대로 시험할 수 있습니다. fetch 를 쓰는 부분은 모델_불러오기() 하나뿐입니다.

/** 3x3 무패딩 합성곱에 ReLU 를 이어서 계산합니다.
 *
 * 두 합성곱층 모두 뒤에 ReLU 가 붙으므로 한 번에 처리합니다.
 */
function 합성곱_렐루(입력, 입력_채널, 입력_크기, 가중치, 편향, 출력_채널) {
    const 출력_크기 = 입력_크기 - 2;
    const 출력 = new Float32Array(출력_채널 * 출력_크기 * 출력_크기);
    const 입력_면 = 입력_크기 * 입력_크기;
    const 출력_면 = 출력_크기 * 출력_크기;

    for (let 출력_c = 0; 출력_c < 출력_채널; 출력_c++) {
        for (let y = 0; y < 출력_크기; y++) {
            for (let x = 0; x < 출력_크기; x++) {
                let 합 = 편향[출력_c];
                for (let 입력_c = 0; 입력_c < 입력_채널; 입력_c++) {
                    const 입력_기준 = 입력_c * 입력_면;
                    const 가중치_기준 = (출력_c * 입력_채널 + 입력_c) * 9;
                    for (let ky = 0; ky < 3; ky++) {
                        const 행_기준 = 입력_기준 + (y + ky) * 입력_크기 + x;
                        const 커널_기준 = 가중치_기준 + ky * 3;
                        합 += 입력[행_기준] * 가중치[커널_기준]
                            + 입력[행_기준 + 1] * 가중치[커널_기준 + 1]
                            + 입력[행_기준 + 2] * 가중치[커널_기준 + 2];
                    }
                }
                출력[출력_c * 출력_면 + y * 출력_크기 + x] = 합 > 0 ? 합 : 0;
            }
        }
    }
    return 출력;
}

/** 2x2 최대풀링. 해상도를 절반으로 줄입니다. */
function 최대풀링(입력, 채널, 입력_크기) {
    const 출력_크기 = 입력_크기 >> 1;
    const 출력 = new Float32Array(채널 * 출력_크기 * 출력_크기);
    const 입력_면 = 입력_크기 * 입력_크기;
    const 출력_면 = 출력_크기 * 출력_크기;

    for (let c = 0; c < 채널; c++) {
        for (let y = 0; y < 출력_크기; y++) {
            for (let x = 0; x < 출력_크기; x++) {
                const 기준 = c * 입력_면 + y * 2 * 입력_크기 + x * 2;
                let 최대 = 입력[기준];
                if (입력[기준 + 1] > 최대) 최대 = 입력[기준 + 1];
                if (입력[기준 + 입력_크기] > 최대) 최대 = 입력[기준 + 입력_크기];
                if (입력[기준 + 입력_크기 + 1] > 최대) 최대 = 입력[기준 + 입력_크기 + 1];
                출력[c * 출력_면 + y * 출력_크기 + x] = 최대;
            }
        }
    }
    return 출력;
}

/** 완전연결층. 가중치는 (출력수, 입력수) 순서로 저장되어 있습니다. */
function 완전연결(입력, 가중치, 편향, 출력_수, 렐루_적용) {
    const 입력_수 = 입력.length;
    const 출력 = new Float32Array(출력_수);
    for (let o = 0; o < 출력_수; o++) {
        let 합 = 편향[o];
        const 기준 = o * 입력_수;
        for (let i = 0; i < 입력_수; i++) 합 += 입력[i] * 가중치[기준 + i];
        출력[o] = 렐루_적용 && 합 < 0 ? 0 : 합;
    }
    return 출력;
}

/** 소프트맥스. 최댓값을 빼서 지수 계산의 넘침을 막습니다.
 *
 * 파이썬 쪽은 로그 소프트맥스 뒤에 지수를 취하는데, 결과는 이것과 같습니다.
 */
function 소프트맥스(점수들) {
    let 최대 = 점수들[0];
    for (let i = 1; i < 점수들.length; i++) if (점수들[i] > 최대) 최대 = 점수들[i];
    const 출력 = new Float32Array(점수들.length);
    let 합 = 0;
    for (let i = 0; i < 점수들.length; i++) {
        const 값 = Math.exp(점수들[i] - 최대);
        출력[i] = 값;
        합 += 값;
    }
    for (let i = 0; i < 출력.length; i++) 출력[i] /= 합;
    return 출력;
}

/** 구조 정보와 가중치 버퍼로 추론 가능한 모델을 만듭니다.
```

`web_version/js/전처리.js` 를 만든다. 세 가지가 파이썬과 어긋나기 쉬우므로 그대로 옮긴다.

첫째, PIL의 Lanczos 는 축소할 때 필터 폭을 축소 배율만큼 넓힌다. 이 처리를 빼면 계단 현상이 남아 인식률이 떨어진다.
둘째, 파이썬 `round()` 는 0.5를 짝수 쪽으로 보내는데 자바스크립트 `Math.round` 는 위로 올린다. 크기 계산과 이동량 계산에서 결과가 갈릴 수 있어 파이썬 방식을 따로 만든다.
셋째, PIL은 가로를 먼저 줄이고 그 결과를 8비트로 반올림해 저장한 뒤 세로를 줄인다. 한 번에 2차원으로 계산하면 값이 달라진다.

```javascript
// 2026-09-21 18:08 KST
//
// 그림판에 그린 그림을 MNIST 와 같은 형식의 28x28 로 다듬습니다.
// desktop_version/app.py 의 전처리() 와 같은 결과를 내야 합니다.
//
// 이 파일은 DOM 에 의존하지 않습니다. 캔버스에서 꺼낸 회색조 배열만 받습니다.

const 최종_크기 = 28;
const 목표_긴변 = 20;   // MNIST 는 숫자를 20x20 안에 맞춰 넣은 데이터입니다.

/** 파이썬 round() 와 같은 반올림.
 *
 * 파이썬은 0.5 를 짝수 쪽으로 보냅니다(round(2.5) == 2). 자바스크립트
 * Math.round 는 위로 올리므로(2.5 -> 3) 그대로 쓰면 크기와 이동량이
 * 파이썬과 갈릴 수 있습니다.
 */
function 짝수_반올림(값) {
    const 내림 = Math.floor(값);
    const 나머지 = 값 - 내림;
    if (나머지 > 0.5) return 내림 + 1;
    if (나머지 < 0.5) return 내림;
    return 내림 % 2 === 0 ? 내림 : 내림 + 1;
}

/** Lanczos3 필터. */
function 란초스(t) {
    if (t < 0) t = -t;
    if (t === 0) return 1;
    if (t >= 3) return 0;
    const 파이t = Math.PI * t;
    return (Math.sin(파이t) / 파이t) * (Math.sin(파이t / 3) / (파이t / 3));
}

/** 한 축의 리샘플링 계수를 PIL 과 같은 규칙으로 계산합니다.
 *
 * 축소할 때는 필터 폭을 배율만큼 넓혀(안티에일리어싱) 여러 입력 픽셀을
 * 함께 섞습니다. 이 처리가 없으면 계단 현상이 남습니다.
 */
function 계수_만들기(입력_크기, 출력_크기) {
    const 배율 = 입력_크기 / 출력_크기;
    const 필터_배율 = Math.max(1, 배율);
    const 지지폭 = 3 * 필터_배율;
    const 계수들 = [];

    for (let 출력 = 0; 출력 < 출력_크기; 출력++) {
        const 중심 = (출력 + 0.5) * 배율;
        const 시작 = Math.max(Math.floor(중심 - 지지폭 + 0.5), 0);
        const 끝 = Math.min(Math.floor(중심 + 지지폭 + 0.5), 입력_크기);
        const 가중치 = new Float64Array(Math.max(끝 - 시작, 1));

        let 합 = 0;
        for (let i = 0; i < 끝 - 시작; i++) {
            const w = 란초스((i + 시작 - 중심 + 0.5) / 필터_배율);
            가중치[i] = w;
            합 += w;
        }
        if (합 !== 0) for (let i = 0; i < 가중치.length; i++) 가중치[i] /= 합;
        계수들.push({ 시작, 가중치, 개수: 끝 - 시작 });
    }
    return 계수들;
}

/** 0~255 범위로 반올림해 자릅니다. PIL 의 8비트 저장과 맞춥니다. */
function 여덟비트로(값) {
    const 정수 = Math.round(값);
    if (정수 < 0) return 0;
    if (정수 > 255) return 255;
    return 정수;
}

/** PIL 과 같은 순서로 가로를 먼저, 세로를 나중에 줄입니다. */
function 축소하기(입력, 너비, 높이, 새_너비, 새_높이) {
    const 가로_계수 = 계수_만들기(너비, 새_너비);
    const 중간 = new Uint8Array(새_너비 * 높이);
    for (let y = 0; y < 높이; y++) {
        for (let x = 0; x < 새_너비; x++) {
            const { 시작, 가중치, 개수 } = 가로_계수[x];
            let 합 = 0;
            for (let i = 0; i < 개수; i++) 합 += 입력[y * 너비 + 시작 + i] * 가중치[i];
            중간[y * 새_너비 + x] = 여덟비트로(합);
        }
    }

    const 세로_계수 = 계수_만들기(높이, 새_높이);
    const 출력 = new Uint8Array(새_너비 * 새_높이);
    for (let y = 0; y < 새_높이; y++) {
        const { 시작, 가중치, 개수 } = 세로_계수[y];
        for (let x = 0; x < 새_너비; x++) {
            let 합 = 0;
            for (let i = 0; i < 개수; i++) 합 += 중간[(시작 + i) * 새_너비 + x] * 가중치[i];
            출력[y * 새_너비 + x] = 여덟비트로(합);
        }
    }
    return 출력;
}

/** 손으로 그린 그림을 MNIST 와 같은 형식의 28x28 로 다듬습니다.
 *
 * 인자:
 *     회색조: 0~255 Uint8Array. 검은 배경에 흰 글씨
 *     너비, 높이: 회색조 배열의 크기
 * 반환:
 *     길이 784 의 Float32Array(0.0~1.0). 그린 것이 없으면 null
 */
export function 전처리(회색조, 너비, 높이) {
    // 1) 글씨가 있는 영역의 경계 상자를 찾습니다.
    let 위 = -1, 아래 = -1, 왼쪽 = 너비, 오른쪽 = -1;
    for (let y = 0; y < 높이; y++) {
        for (let x = 0; x < 너비; x++) {
            if (회색조[y * 너비 + x] !== 0) {
                if (위 < 0) 위 = y;
                아래 = y;
                if (x < 왼쪽) 왼쪽 = x;
                if (x > 오른쪽) 오른쪽 = x;
            }
        }
    }
    if (위 < 0) return null;   // 아무것도 그리지 않은 빈 캔버스

    const 상자_너비 = 오른쪽 - 왼쪽 + 1;
    const 상자_높이 = 아래 - 위 + 1;
    const 잘라낸 = new Uint8Array(상자_너비 * 상자_높이);
    for (let y = 0; y < 상자_높이; y++) {
        for (let x = 0; x < 상자_너비; x++) {
            잘라낸[y * 상자_너비 + x] = 회색조[(위 + y) * 너비 + 왼쪽 + x];
        }
    }

    // 2) 비율을 유지한 채 긴 변이 20픽셀이 되도록 줄입니다.
    const 비율 = 목표_긴변 / Math.max(상자_너비, 상자_높이);
    const 새_너비 = Math.max(1, 짝수_반올림(상자_너비 * 비율));
    const 새_높이 = Math.max(1, 짝수_반올림(상자_높이 * 비율));
    const 축소 = 축소하기(잘라낸, 상자_너비, 상자_높이, 새_너비, 새_높이);

    // 3) 28x28 검은 도화지 한가운데에 붙입니다.
    const 도화지 = new Uint8Array(최종_크기 * 최종_크기);
    const 시작_x = (최종_크기 - 새_너비) >> 1;
    const 시작_y = (최종_크기 - 새_높이) >> 1;
    for (let y = 0; y < 새_높이; y++) {
        for (let x = 0; x < 새_너비; x++) {
            도화지[(시작_y + y) * 최종_크기 + 시작_x + x] = 축소[y * 새_너비 + x];
        }
    }

    // 4) 무게중심을 (13.5, 13.5) 로 옮깁니다. MNIST 가 그렇게 만들어진 데이터입니다.
    let 전체_밝기 = 0, 가중_y = 0, 가중_x = 0;
    for (let y = 0; y < 최종_크기; y++) {
        for (let x = 0; x < 최종_크기; x++) {
            const 값 = 도화지[y * 최종_크기 + x];
            전체_밝기 += 값;
            가중_y += y * 값;
            가중_x += x * 값;
        }
    }

    let 결과_배열 = 도화지;
    if (전체_밝기 > 0) {
        const 이동_x = 짝수_반올림(13.5 - 가중_x / 전체_밝기);
        const 이동_y = 짝수_반올림(13.5 - 가중_y / 전체_밝기);
        if (이동_x !== 0 || 이동_y !== 0) {
            결과_배열 = new Uint8Array(최종_크기 * 최종_크기);
            for (let y = 0; y < 최종_크기; y++) {
                const 원_y = y - 이동_y;
                if (원_y < 0 || 원_y >= 최종_크기) continue;
                for (let x = 0; x < 최종_크기; x++) {
                    const 원_x = x - 이동_x;
                    if (원_x < 0 || 원_x >= 최종_크기) continue;
                    결과_배열[y * 최종_크기 + x] = 도화지[원_y * 최종_크기 + 원_x];
                }
            }
        }
    }

    // 5) 0~255 를 0.0~1.0 으로 바꿉니다. 정규화는 부르는 쪽에서 합니다.
    const 결과 = new Float32Array(최종_크기 * 최종_크기);
    for (let i = 0; i < 결과.length; i++) 결과[i] = 결과_배열[i] / 255;
    return 결과;
}
```

1. **PIL 의 Lanczos 는 축소할 때 필터 폭을 배율만큼 넓힙니다.** 이 처리를
   빼면 계단 현상이 남아 인식률이 떨어집니다. 브라우저의 `drawImage` 축소
   보간은 명세가 없어 브라우저마다 결과가 다르므로 쓰지 않습니다.
2. **파이썬 `round()` 는 0.5 를 짝수 쪽으로 보냅니다.** 자바스크립트
   `Math.round` 는 위로 올리므로, 크기와 이동량 계산에는 `짝수_반올림()` 을
   씁니다.
3. **PIL 은 가로를 먼저 줄이고 8비트로 반올림한 뒤 세로를 줄입니다.**
   한 번에 2차원으로 계산하면 값이 달라집니다.

한쪽을 고치면 반드시 `골든_만들기.py` 를 다시 돌리고 검증을 통과시키세요.
